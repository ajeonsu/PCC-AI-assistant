# Web Frontend & Chat Agent (Phase 3)

This directory will host the **Next.js (App Router, TypeScript) + Vercel AI SDK + Supabase Auth** chat application.

When deploying to **Vercel (Hobby / Free)**:
- Set **Root Directory** to `web` in your Vercel project settings.
- Configure your environment variables (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `GROQ_API_KEY`, `GEMINI_API_KEY`, `ALLOWED_USER_EMAIL`).
